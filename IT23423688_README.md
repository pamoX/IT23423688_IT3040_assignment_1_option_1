## How To Run The Project

1. Install Python.
2. Open a terminal in the project folder.
3. Install dependencies:

```bash
pip install -r IT23423688_requirements.txt
```

4. Install Playwright browser support:

```bash
playwright install
```

5. Run the automation:

```bash
python IT23423688_test_automation.py --excel "IT23423688_Test cases.xlsx"
```

6. Optional headless run:

```bash
python IT23423688_test_automation.py --excel "IT23423688_Test cases.xlsx" --headless
```

## Output

The automation opens the translator UI, enters each Singlish input from the Excel sheet, collects the Sinhala output, and writes results back to the workbook.

Output columns:

- `Actual output`
- `Status`

Status values:

- `PASS` - Actual output exactly matches expected output.
- `FAIL` - Actual output does not match expected output.
- `COLLECTED` - Actual output was collected but no expected output was available.
- `UI Error` - The automation could not complete the UI interaction for that row.
